# Upstream and fork policy

This fork starts from [blancodagoat/texoverride](https://github.com/blancodagoat/texoverride), tag
`v0.7.3`, commit `73f09bac0b045dfce4d96ae1dd9273e32cfdade0`.

The original MIT copyright and MinHook notices remain in [LICENSE](LICENSE). Fork-specific changes
are listed at the top of [CHANGELOG.md](CHANGELOG.md).

The built-in update check intentionally continues to report newer upstream releases. A newer
upstream version should be reviewed and merged into this branch, not installed blindly over the
fork. The fork version suffix does not prevent a future upstream `0.7.4` or later from being
reported.

The local development branch is `emk/performance-v0.7.3`. Until an authenticated GitHub remote is
added, the repository under this project folder is the canonical local fork.
